# Fluid-Quality-and-Monitoring-Unit-using-Arduino

## Project Overview
This project is a low-cost, IoT-ready embedded system for real-time monitoring of fluid quality parameters. The system measures Temperature, Turbidity, Depth, and pH using sensors connected to an Arduino Uno. Results are displayed on an LCD screen, and the system provides alerts when abnormal readings are detected, demonstrating a practical approach to environmental monitoring and sustainability.

## Technical Details
Hardware: Arduino Uno, pH sensor, turbidity sensor, temperature sensor, ultrasonic depth sensor, LCD screen
Software: Arduino IDE (C/C++), signal conditioning code, calibration routines
Skills Applied: Embedded system design, sensor interfacing, data acquisition, signal processing, real-time monitoring, testing & validation

## Conclusion
This system provides automated, continuous monitoring of fluid quality, reducing manual effort and enabling timely action for environmental sustainability. It can be adapted for IoT-based remote monitoring, supporting smart water management systems in communities or laboratories.
